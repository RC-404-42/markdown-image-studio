# Markdown 文章圖片工坊 — iPhone PWA

可安裝到 iPhone 主畫面的離線 Markdown 文章圖片工具。所有文章、圖片、字體與輸出都只在瀏覽器內處理，不會傳送到伺服器。

## 1.1.0 更新

- 編輯器新增復原、重做，以及圖像化的剪下、複製、貼上按鈕；也支援 Ctrl/Cmd+Z、Ctrl/Cmd+Y 與 Ctrl/Cmd+Shift+Z。
- 連結工具改為直覺的鏈條圖示，排版新增靠右對齊。
- 新增「全部重設」，可一次還原範例草稿、配色、排版與輸出設定。
- 新增「櫻霧」與「夜藤」配色，並提供兩個會保存在目前瀏覽器中的自訂配色欄位。
- 保留 1.0.5 的跨裝置輸出修正，並同步改善行內程式碼在圖片中的定位一致性。

## 1.0.5 更新

- 待辦清單勾選框改為工具自行繪製，不再依賴 Safari 與桌面瀏覽器各自不同的原生控制項；iPhone 輸出會保有清楚、飽滿的勾選效果。
- 新增多組可完全離線使用的英文與日文字體預設，會依 Windows、macOS、iPhone 上已安裝的系統字體自動選用最合適的字型。
- 單張長圖會在輸出副本完成排版後再量一次真正的內容底部，進一步減少 iPhone 字體替換造成的下方多餘留白，並保留底部圓角。

## 1.0.4 修正

- 將預覽中每個 Markdown 元素的實際計算樣式直接寫入輸出副本，修正 PC 偶發遺失引用框、表格、程式碼區塊與字級間距的問題。
- 單張長圖改用文章內容的實際底部位置加上設定中的下留白計算高度，不再沿用可能偏大的容器高度。
- 桌面與 iPhone 會使用同一份已固定的排版結果，縮圖、下載成品與即時預覽更一致。

## 1.0.3 修正

- 將輸出引擎更新為支援 CSS Color Level 4 的 `html2canvas-pro`，修正 iPhone Safari 的 `unsupported color function "color"` 錯誤。
- 輸出時只載入文章專用的安全樣式，不再把整套介面 CSS 塞進擷取文件。
- 將輸出卡片移到乾淨的擷取文件原點，並用實際內容高度鎖定畫布，修正 PC 圖片縮放、偏移、裁切與黑色空白。
- 修正安全性政策誤擋動態排版樣式的問題，讓 PC 的畫布寬度、留白與輸出尺寸一致。
- 更新離線快取版本；原本保存在同一網址的文章草稿與設定會繼續保留。

## 功能

- CommonMark 與常用 GFM 排版、表格、待辦清單及程式碼上色
- 字體／本機字體、字級、行距、字距、段距、縮排與四邊留白
- 編輯復原／重做、剪下／複製／貼上、左右／置中／靠右對齊
- 六組內建配色與兩組自訂配色記錄
- PNG、JPG、WebP；長圖、固定高度及手動分頁
- iOS 系統分享選單、逐張下載及 Markdown 原稿備份
- PWA 主畫面安裝與 Service Worker 離線快取
- 手機畫布記憶體保護，過長內容自動安全分張

## 部署

請閱讀 [`GITHUB-PAGES-教學.md`](./GITHUB-PAGES-教學.md)。這個修正版已將所有必要檔案放在同一層；不要上傳 ZIP 本身，請先解壓縮，再把裡面的全部檔案上傳到 Repository 最外層。

## 隱私

GitHub Pages 只提供這套工具的靜態程式碼。文章草稿儲存在裝置的瀏覽器儲存空間；遠端圖片預設不載入，必須使用工具列按鈕選擇本機圖片。

重要原稿仍建議定期使用「備份 .md」保存到 iCloud Drive 或其他位置，不要把瀏覽器草稿當成唯一備份。
